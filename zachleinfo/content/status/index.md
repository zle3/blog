## About these checks

Each check times a single request from your browser to that part of the site. The site is static and served by Cloudflare Pages, so if this page loaded at all, the website itself is up. A failing check most often means a network or ad-blocker issue on your side. Ad blockers commonly block the view counter check, for example.

For problems with Cloudflare itself, see the [Cloudflare status page](https://www.cloudflarestatus.com/). The community platform from the [blog series](/blog/2026/ai-agent-platform-part-1) has its own status page, which is separate from this one.
